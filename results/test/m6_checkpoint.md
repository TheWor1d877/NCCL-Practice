# 模块 6：训练侧纸面账

状态：纸面，不跑程序。

## checkpoint 容量账

70B 参数的混合精度 Adam 训练，每个参数在 checkpoint 里占 16 字节：

| 项 | 每参数字节 |
|---|---|
| fp32 主权重 | 4 |
| fp16 参数副本 | 2 |
| fp16 梯度 | 2 |
| Adam 一阶动量 | 4 |
| Adam 二阶动量 | 4 |
| 合计 | 16 |

总量 70×10⁹ × 16 B = 1.12 TB。

分片到 1024 卡：1120 GB ÷ 1024 ≈ 1.1 GB/卡。

每 rank 写自己的分片，不让所有 rank 读同一份对象存储。若 1024 个 rank 同时读一个大对象，元数据服务的请求量先打满，带宽还没成为瓶颈时就已卡死；分片后每个 rank 只碰自己的键，元数据压力随分片数线性摊开。

## 保存间隔

公式 T = √(2·C·F)，C 是存一次 checkpoint 的耗时，F 是平均故障间隔。

代入假设值 C = 120 s、F = 4 小时 = 14400 s：

T = √(2 × 120 × 14400) = √3 456 000 ≈ 1859 s ≈ 31 分钟。

C 和 F 都是假设值，未在本机实测。检查点间隔取这个量级的意义：间隔太长，故障时丢的进度多；间隔太短，存储写入挤占训练时间。

## 慢节点与网络故障的区分顺序

训练变慢时，先查单节点自身：CPU 占用、磁盘 IO、数据加载吞吐。这三项都正常，再怀疑网络链路。

顺序反过来的代价：数据加载慢会被误判成链路故障，换网卡、换交换机都解决不了，白花时间。单节点排查的单项成本低、结论确定，先做。
