# m3_07 kernel 融合（RMSNorm + LSA）

调用的 API：同样用 `ncclDevCommCreate` / `ncclGetLsaPointer` / `ncclTeamTagLsa`，在一个 kernel 里先做 RMSNorm 再跨卡归约，`ncclGetLocalPointer` 取本卡地址参与计算。

教了什么：归一化计算和 all-reduce 融合进同一次 launch，对应推理每层 forward 的真实模式；配置为 2 rank、序列 128、hidden 1024、每卡 64 token，结果校验通过。

报错与解决：无。只编了 `01_rmsnorm_lsa/c` 这一个子项，其余子项依赖 multimem 或 GIN，编了也跑不了，退出码 0。
