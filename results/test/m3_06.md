# m3_06 kernel 内通信（LSA）

调用的 API：`ncclDevCommCreate` 把通信器转成设备侧可用的 devComm，kernel 内用 `ncclGetLsaPointer` 取对端显存地址、`ncclTeamTagLsa` 圈定团队，配 `ncclCoopCta` 做 block 内同步。

教了什么：通信的发起从 CPU 侧挪进了 GPU kernel，省掉 kernel 外发起的启动开销；日志里每卡建了 16 个 LSA barrier，双卡 4MB all-reduce 结果校验通过。

报错与解决：无，退出码 0。其余子项按教程不跑：`02_alltoall_gin`、`03_alltoall_hybrid` 需要 GIN 的 RDMA 网络，单机没有；`05/06` 两个 CFT 子项需要 multimem，Ampere 不支持。
