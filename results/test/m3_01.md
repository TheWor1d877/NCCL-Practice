# m3_01 通信器创建

调用的 API：`ncclCommInitAll`（单进程多卡）、`ncclCommInitRank` + `ncclGetUniqueId`（pthread 与 MPI 两种方式）。

教了什么：同一个双卡通信组有三种组织方式，uniqueId 的传递路径不同——单进程内直接由 API 建好，pthread 用共享内存里的 uniqueId 建，MPI 用 `MPI_Bcast` 广播 uniqueId。

报错与解决：`mpirun` 报 `could not access or execute an executable`，退出码 132。原因是 `01_communicators/Makefile` 的 `EXAMPLES` 默认不含 03 子项，要 `MPI=1` 才编；进 `03_one_device_per_process_mpi/c` 单独 `make` 后重跑，输出 rank0/rank1 建通信器与销毁的全过程，退出码 0。
