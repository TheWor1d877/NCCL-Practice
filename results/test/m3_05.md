# m3_05 对称内存

调用的 API：`ncclMemAlloc` + `ncclCommWindowRegister` 把各卡 buffer 注册成对称内存窗口，分别用 `ncclAllReduce` 和 `ncclAllGather` 跑了一遍，结束用 `ncclCommWindowDeregister` 注销。

教了什么：两个 rank 的 buffer 地址与布局完全对称，通信时可以直接按对端偏移寻址，是 NCCL 面向小消息低延迟的新机制；`allgather_ce` 还演示了借 copy engine 做 allgather。

报错与解决：无。系统 libnccl 2.32.6 高于该示例要求的 2.27，两个子项均通过，退出码 0。
